ARES PWA – Prototyp-Paket

Dateien:
- index.html: App-Oberfläche
- manifest.webmanifest: PWA-Metadaten
- sw.js: Offline-Caching
- icon.svg: App-Symbol

Wichtig:
Eine PWA lässt sich nur über HTTPS oder localhost installieren. Die Dateien müssen daher auf einem HTTPS-Webhost liegen. Das ZIP allein installiert die App noch nicht.

Schneller Weg:
1. ZIP entpacken.
2. Die vier Dateien in einen statischen HTTPS-Host hochladen (z.B. GitHub Pages).
3. Die veröffentlichte HTTPS-Adresse in Chrome auf Android öffnen.
4. Chrome-Menü (⋮) > „App installieren“ oder „Zum Startbildschirm hinzufügen“.

Der aktuelle Prototyp verwendet fest eingetragene, historische Simulationswerte.
Er verbindet sich nicht mit Binance, führt keine Orders aus und speichert keine API-Schlüssel.
